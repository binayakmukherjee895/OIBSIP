### 3. Basic Weather App

A terminal-based weather application that retrieves current weather information for a user-specified city using the **OpenWeather API**.

The application handles user input, API requests, JSON responses, HTTP errors, network errors, and missing weather data.

**Information displayed:**

* City
* Temperature
* Humidity
* Weather description

**Concepts used:**

* Python
* API integration
* HTTP requests
* JSON data
* `requests`
* Environment variables
* `python-dotenv`
* Error handling
* Input validation

📂 **Project:** [`3. Weather`](./3.%20Weather/)
📄 **README:** [`View Weather App README`](./3.%20Weather/README.md)

## 🔐 Security

The Weather App uses an OpenWeather API key stored in a local `.env` file.

The `.env` file is excluded from version control using `.gitignore` and is **not included in this repository**.

API keys and other sensitive credentials should never be committed to a public GitHub repository.
